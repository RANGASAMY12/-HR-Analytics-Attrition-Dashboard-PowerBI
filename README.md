# HR Analytics - Employee Attrition Dashboard

## Business Problem
Company la 16.1% employees velila poranga. HR ku yen nu theriyala. Overtime, Salary, Department effect-a analyze panninen.

## Dataset
- Source: IBM HR Analytics (Kaggle)
- Rows: 1470 Employees, 35 Columns

## Tools Used
- SQL - Data Cleaning & Attrition Calculation
- Power BI - 2 Page Interactive Dashboard
- Excel - Data Validation

## Dashboard Preview
![HR Dashboard](hr-dashboard.png)

## Key Insights Found
1.  **Overall Attrition 16.1%** - 237 employees left
2.  **Sales Department Highest** - 20.6% attrition (92 members)
3.  **Overtime = Main Reason** - OT pannuravanga 30% left, OT pannathavanga 10% thaan
4.  **Age Factor** - 25-30 age group la attrition 25%
5.  **Low Income** - Monthly Income < 3000 irukuravanga la attrition 2x

## My Recommendations
- Overtime ku extra incentive 15% kudukanum
- Sales team ku salary hike + work-life balance
- New joiners ku mentorship program (0-2 years la attrition jaasthi)
